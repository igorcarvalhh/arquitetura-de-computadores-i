# arquitetura-de-computadores-i
Anotações da disciplina de Arquitetura de Computadores I - UERJ 2026.1

## Arquitetura x86
Este tópico é dedicado a aqueles que tenham interesse ou curiosidade em saber como programar em linguagem de montagem usando a arquitetura da intel (x86)
- [Minimanual de x86 (windows)](https://www.cs.virginia.edu/~evans/cs216/guides/x86.html) - Pequeno manual descrevendo as instruções de x86 para montadores da Microsoft em ambiente windows
- [Minimanual de x86 (várias plataformas)](https://cs.lmu.edu/~ray/notes/x86assembly/) - Pequeno manual descrevendo os ambiente de programação de linguagem de montagem de x86 para vários montadores. Cobre o ambiente Linux
- [Exemplos de programas em linguagem de montagem](https://cs.lmu.edu/~ray/notes/gasexamples/) - Página com exemplos de programas escritos em linguagem de montagem usando o montador da GNU. Parte do código tem integração com programas escritos em C
